# RUGBY vs FOOTBALL

15인제 럭비 유니언과 NFL 미식축구의 차이점을 비교하는 교육용 웹사이트입니다.

## 주요 기능
- 패스 규칙
- 보호장비와 몸싸움
- 출전 선수 및 교체
- 경기 진행 방식과 시간
- 득점 방식
- 종목 비교표와 O/X 퀴즈
- 반응형 웹 디자인

## 실행 방법
`index.html`을 브라우저로 열거나 VS Code Live Server 확장으로 실행합니다. 별도 설치는 필요하지 않습니다.

## GitHub Pages 배포
저장소 Settings > Pages > Deploy from a branch > main / (root)를 선택합니다.

## 사용 기술 및 오픈소스
HTML5, CSS3, JavaScript (외부 JS 라이브러리 없음). Google Fonts의 DM Sans와 Noto Sans KR을 사용합니다.

## 팀원 및 역할
- 팀장: 저장소 관리 및 메인 화면
- 팀원 A: 패스 규칙 / 보호장비와 몸싸움
- 팀원 B: 출전 선수 및 교체 / 경기 진행 방식과 시간
- 팀원 C: 득점 방식 / 디자인 및 테스트

> 실제 담당자 이름, 스크린샷, 작업 내역은 제출 전에 업데이트하세요.

## 규칙 기준
15인제 럭비 유니언 및 NFL 미식축구의 일반적인 경기 규칙을 기준으로 작성했습니다. 대회·시즌별 세부 규정은 다를 수 있습니다.

공식 규칙 참고: https://www.world.rugby/the-game/laws/home / https://operations.nfl.com/the-rules/nfl-rulebook/
